## CC攻击单独说：防御G数救不了登录接口

买高防时容易忽略的一点：DDoS和CC是两种攻击，防护逻辑不同。流量攻击比的是带宽，用G数衡量；CC攻击比的是请求量，打的是应用层——登录、查询、下单这些消耗资源的接口，几十M的恶意请求流就能把后端拖垮，再高的防御G数也未必接得住。

应用层防护靠策略和算法。专业抗D服务公开的做法包括IP画像、行为分析、Cookie挑战这类多维判定，再用自动化引擎持续更新规则。IDC方面的做法差异很大：有的标“无视CC”，有的标“无限抗CC+秒解”，还有的把CC防御做成可选开关，比如Raksmart就写明由用户自主决定是否开启。买之前多问一句“CC策略默认开不开、能不能按业务自定义规则”，能省掉很多事后扯皮。
